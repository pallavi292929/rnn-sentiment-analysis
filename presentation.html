Problem Statement

Raw review text is noisy. Models need it clean.

The IMDB dataset packs 50,000 movie reviews labeled positive or negative — but straight from the source, that text is full of HTML leftovers, stray URLs, inconsistent punctuation and casing, and filler words that add noise without adding meaning. The real work of this project is building a preprocessing pipeline that strips all of that away before any model ever sees the text.

Approach — Preprocessing Pipeline

Six steps, applied to every single review.

01

Lowercase

Normalizes casing across the whole corpus.

02

Remove URLs

Strips any http links via regex.

03

Remove punctuation

Keeps only letters, numbers, and spaces.

04

Remove HTML tags

Cleans up leftover <br />-style scrape artifacts.

05

Remove stopwords

Tokenizes with NLTK, filters common English stopwords.

06

Stemming

Reduces words to their root form with a Porter Stemmer.

Approach — Model

TF-IDF vector in, sentiment out.

Cleaned reviews are vectorized into a 5,000-dimensional TF-IDF representation, then passed through a single-layer RNN with a fully-connected output and sigmoid activation for binary classification.

Next Steps

Where this model could go from here.

  • Fix stopword removal
    Current substring-based removal can strip letters out of unrelated words — rebuilding from filtered tokens is safer.
  • Use word embeddings
    A single TF-IDF vector as one timestep doesn't let the RNN use its sequential strength — real word sequences with embeddings would.
  • Try LSTM / GRU
    Better than vanilla RNN at capturing longer-range dependencies in review text.
  • Bidirectional RNN
    Sentiment often depends on context from both directions in a sentence.
  • Fine-tune a transformer
    A pretrained model like DistilBERT would likely push accuracy well past 85.67%, at the cost of more compute.
